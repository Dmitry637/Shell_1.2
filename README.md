# Эмулятор командной оболочки UNIX-подобных ОС (Этап 1: REPL)

Добро пожаловать в репозиторий проекта, посвященного разработке эмулятора командной оболочки (Shell) для UNIX-подобных операционных систем. Данный программный продукт написан на языке Java и представляет собой реализацию **первого этапа** разработки, целью которого является создание минимального, но полностью работоспособного прототипа.

Основная задача текущего этапа — реализация цикла **REPL** (Read-Eval-Print Loop), что означает непрерывный цикл чтения ввода пользователя, его обработки и вывода результата. На данном этапе большинство команд представляют собой заглушки (stubs), однако диалог с пользователем, парсинг команд и обработка ошибок уже полностью поддерживаются.

## 🚀 Реализованный функционал

В соответствии с техническим заданием, в текущей версии приложения реализованы следующие возможности:

1. **Консольный интерфейс (CLI):** Приложение работает в интерактивном режиме, взаимодействуя с пользователем через стандартные потоки ввода (`stdin`) и вывода (`stdout`). Это позволяет использовать эмулятор в любой современной терминальной среде.
2. **Динамическое приглашение к вводу (Prompt):** Строка приглашения не является статичной. Она формируется на основе реальных данных операционной системы, в которой запущен эмулятор, и имеет формат `username@hostname:~$`. Имя пользователя извлекается через системные свойства Java, а имя хоста — через сетевые интерфейсы.
3. **Парсер команд:** Реализован собственный лексер, который разбивает введенную строку на команду и аргументы. Парсер корректно обрабатывает:
    * Разделение по пробелам и табуляциям.
    * Одинарные (`'`) и двойные (`"`) кавычки (позволяет передавать аргументы с пробелами).
    * Обработку ошибки «незакрытой кавычки» (No closing quotation) без аварийного завершения программы.
4. **Команды-заглушки:** Реализованы базовые команды `ls` и `cd`. На данном этапе они не выполняют реальных действий с файловой системой, а лишь выводят свое имя и переданные аргументы. Это необходимо для проверки работы парсера и цикла REPL.
5. **Команда завершения работы:** Команда `exit` корректно завершает цикл REPL и закрывает приложение. Предусмотрена проверка на наличие лишних аргументов.
6. **Обработка ошибок:** Программа устойчива к некорректному вводу. Она обрабатывает пустые строки, неизвестные команды и синтаксические ошибки парсинга, выводя соответствующие сообщения в консоль.
